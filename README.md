## 技术方案概述

系统后端基于 FastAdmin+ThinkPHP 开发，前端为 H5 版本，无需小程序审核，用户通过链接、二维码直接打开访问，转发分享门槛更低；后台拥有成熟的 RBAC 权限、订单管理、资金流水、内容审核机制，方便运营方管理、风控审核。整套源码支持 LNMP 环境部署，代码可二次定制，用户数据、订单数据自主掌控，不依赖第三方平台。
平台角色区分：平台管理员、搭子 / 助教（服务提供者）、普通用户，权限相互隔离；支持入驻审核机制，助教、搭子入驻需要提交资料，后台审核通过之后才能发布服务、接单，降低平台风险。

## 核心功能模块

### 1. 同城搭子主页与附近推荐

打开 H5 自动定位，基于城市、距离做附近搭子、附近活动推荐。首页可可视化装修，设置轮播 banner、分类导航：运动搭子、桌游剧本、探店聚餐、K 歌游玩、游戏陪玩、学习助教、技能陪练等类目。支持按城市、距离、性别、标签筛选搭子，个人主页展示简介、擅长项目、相册、评价、接单价格、档期，用户可以查看口碑、发起咨询。

### 2. 线下活动组局发布与报名

搭子或者管理员可以自主发起线下组局活动，填写活动主题、时间地点、人数上限、费用、活动介绍、报名要求，上传活动海报。支持 AA 制、主办方收费两种模式。感兴趣用户在线报名支付，报名成功生成报名凭证。
活动支持设置报名截止时间、自动成团、人数不足自动退款；后台统一管理活动审核，违规活动可驳回下架。活动结束后可以发布相册、评价，形成活动口碑沉淀。适合羽毛球、爬山、露营、饭局、桌游局等兴趣组队场景。

### 3. 陪约玩、助教服务下单预约

这是系统核心的约玩服务板块，助教 / 搭子上架可预约服务，设置单价、服务时长、可服务范围（同城到店、上门、线上陪练）、可预约时间段。用户选择服务、预约时间、下单支付。
订单流程完整：下单→待接单→确认服务→服务完成→确认收货。支持平台担保交易，服务完成后资金结算给搭子，减少双方纠纷。支持预约档期管理，搭子设置自己空闲时间，避免时间冲突。

### 4. 聊天沟通、评价口碑体系

内置 IM 聊天功能，下单前后双方可以在线沟通细节，确认地点、需求；聊天内容后台可留存，便于纠纷核查。服务或者活动结束后，用户可以对搭子进行评分、文字评价，评价对外展示，形成口碑体系，优质搭子优先推荐。同时支持举报功能，违规用户、违规内容运营可以快速处理。

### 5. 资金结算、佣金与分销裂变

平台可设置抽佣比例，不管是活动订单还是陪约订单，成交后自动扣除平台佣金，剩余收益进入搭子钱包。搭子可在后台申请提现，管理员审核打款，资金流水、订单明细全部可查，支持导出对账。
自带分销推广功能，每个用户拥有专属推广链接，邀请好友注册、下单，推广人获得奖励，助力平台在本地社群裂变拉新。同时配套优惠券、新人福利，用来吸引新用户首次下单。

### 6. 内容风控、用户管理与数据看板

后台拥有内容审核开关，搭子资料、活动内容、服务介绍、聊天信息可配置人工审核，规避违规信息。用户管理支持账号封禁、黑名单。数据看板统计注册量、活动数量、订单成交额、热门服务类目、热门城市，用图表直观展示平台运营情况，报表支持导出 Excel。
配套消息通知，订单状态变更、接单提醒、活动成团通知、提现审核结果通过短信或者 H5 消息推送。

## 方案优势

对比小程序，纯 H5 版本优势在于上线快，不用微信小程序资质审核，改完链接就能分发传播；支持私有化部署，平台规则自主制定，抽佣、入驻门槛自定义。既有活动组局的社群玩法，又有陪约助教预约下单的服务电商能力，把 “兴趣组队” 和 “付费约玩” 融合在一套系统内。源码支持二次开发，可以按需扩展小程序端、实名认证、人脸核验、更多风控能力。
